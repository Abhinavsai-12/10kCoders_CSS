# 10kCoders CSS Practice

## About the Project
This repository contains CSS practice tasks completed as part of the 10kCoders training program. It includes different styling exercises and web page designs created to learn and practice CSS concepts.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open any `.html` file.
4. Run the file in a web browser to view the webpage.
5. Make changes to the CSS files to practice different styling properties.
